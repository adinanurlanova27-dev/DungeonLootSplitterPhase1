Logic Explanation

How the Loot Array Works: At the top of js/script.js, I keep a lootInventory array in memory while the page is open. Each valid item is stored as an object with name and value properties so every part of the app reads from the same list.

Where Loops Are Used: Inside addLoot(), a for loop checks for duplicate item names and nested for loops sort items from highest to lowest value. Inside renderLoot(), a for loop builds each list item in the DOM, and inside calculateTotalLoot(), a for loop adds up every item's value.

How if Statements Make Decisions: Conditional if statements validate user input before changing state or dividing loot. In addLoot(), if checks reject blank names, duplicate names, empty/non-numeric amounts, and negative numbers. In splitLoot(), if checks verify that the party size is a whole number of at least 1 and that loot items exist before calculating each member's share.
